### Projetos

- **Voz** — Aplicação desktop de chamadas de voz, vídeo e compartilhamento de tela P2P, sem cadastro e sem servidor próprio. Electron, WebRTC e Nostr.
- **Sistema de Auditoria de Qualidade** — Sistema em Python que usa IA para analisar documentação, gerar checklists e conduzir auditorias.
- **PDV Elmix** — Sistema de vendas para uma empresa de produtos naturais, desenvolvido em JavaFX com design patterns e ORM.
- **PUCaronas** — Plataforma de caronas para a comunidade acadêmica da PUCPR, com API REST em PHP e banco de dados MySQL.
- **Sistema de Bloqueio de Ignição por Álcool** — Sistema que impede a partida do veículo ao detectar álcool no condutor.
- **Bot para Discord** — Bot desenvolvido em Node.js.
